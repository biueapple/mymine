# mymine ⛏️

## 🎮 프로젝트 소개
**mymine**은 샌드박스와 RPG 요소를 결합한 Unity 기반 게임입니다.  
월드 생성, 블록 시스템, 유닛 조작, 인벤토리 및 조합 시스템 등 마인크래프트 스타일의 기능들을 직접 설계하고 구현하며 구조적 사고와 알고리즘 중심 개발을 중점으로 진행한 개인 프로젝트입니다.

- **개발 엔진**: Unity 2022.3.4f1
- **장르**: 샌드박스 / RPG
- **개발 기간**: 약 1년
- **스크립트 GitHub**: [https://github.com/biueapple/mymine](https://github.com/biueapple/mymine)

---

## 🛠 주요 기술 및 시스템

### 🧱 월드와 블록 시스템
- 일반 큐브 대신 직접 정점 정보를 바탕으로 메쉬 생성 → **렌더링 최적화**
- **보이는 면만 렌더링**, 면마다 다른 텍스처 적용 가능
- URP 환경에서 빈 마테리얼 처리 이슈 해결

### 🔁 충돌 처리
- MeshCollider 비효율성 문제로 **블록 존재 여부 기반 충돌 시스템** 구현
- 추후 반블록/계단 대응 위해 `Vector * Matrix` 와 `Point in Polyhedron` 알고리즘 실험

### 🕹 유닛 움직임
- Rigidbody 없이 직접 구현한 **velocity / momentum 기반 이동 시스템**
- 배고픔, 외부 힘, 점프 상태 등을 반영한 자연스러운 이동 처리

### 🍗 배고픔 시스템
- 움직인 거리 기반 배고픔 소모
- Y축 낙하 시 배고픔 소모 제외 처리

### 🌍 월드 생성 / 바이옴
- 월드를 청크 단위로 분할 생성
- 바이옴을 기반으로 나무, 지하 구성 등 디테일 생성 분리

### 🎒 인벤토리
- 인터페이스 기반 다형성 구조  
  (예: `IItem`, `IEquip`, `IConsume`을 조합해 다양한 아이템 타입 생성)
- ScriptableObject 기반에서 일반 클래스로 전환하여 유연성 확보

### 🔨 아이템 조합 시스템
- 조합 입력을 **Slice 방식**으로 정규화해 다양한 배열 대응
- **해시 기반 조합 검색**으로 효율 향상
- 콜백 방식으로 조합 완료 후 재료 소모 처리

### 💥 스킬 및 전투 시스템
- 스킬 UI와 논리 분리 → 비활성화 상태에서도 정상 작동
- 공격 모션과 스킬을 분리하여 다양한 공격 스타일을 구성 가능
- 데코레이터 패턴 기반 투사체 시스템 (이동, 충돌, 효과 모듈화)

### 👾 적 AI
- 기본 A* 경로탐색 기반 이동
- 행동 트리 기반으로 도망, 뒤로 숨기 등 다양한 반응 구현
- 군집 행동 및 충돌 방지 알고리즘 실험

### 🖱 플레이어 입력 모드
- Normal (블록 설치/파괴) ↔ Battle (공격/스킬) 모드 전환
- 각 입력 모드에 따라 UI 및 처리 방식 변경

## 🎯 구현 의도 및 성과
- 단순 구현을 넘어서 **성능, 구조, 확장성**을 고려한 실험적 개발
- 다양한 시스템을 **직접 설계하고 충돌 및 최적화 이슈를 해결**하며 문제 해결 능력 향상
- 개인 프로젝트이지만 대형 게임 시스템의 구조를 이해하고 재현하려는 목표로 설계
